覆面算パズル

文字に 0〜9 の数字を当てはめる、計算パズルの探偵ゲーム。
式が成り立つ数字の組み合わせを見つけ出そう！

SEND + MORE = MONEYいちばん有名な覆面算。答えは 9567 + 1085 = 10652
あそびかた　・同じ文字には同じ数字、ちがう文字にはちがう数字が入ります。・いちばん先頭の文字には 0 は入りません。・文字をタップして、数字パッドから数字を入れてください。「答え合わせ」で式が成り立つか確かめられます。・困ったら段階ヒント。ヒントを全部開くと「答えを見る」も使えます。

収録した問題は、すべてコンピューターで全探索して「解けること」と解の個数を確かめたものだけです。
